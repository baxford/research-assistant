# Researcher — Browser Extension

Save any web page to your local research assistant with one click.

## Install

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (toggle, top right)
3. Click **Load unpacked** and select this `extension` folder

The Researcher icon will appear in your toolbar.

## Usage

Navigate to any page, click the extension icon, and hit **Save**. The page is sent to your local Researcher instance running at `http://localhost:3001`.
